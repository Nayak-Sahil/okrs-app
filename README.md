## Product: OKR ( Objectives and Key Results )
User stories
- As a user, I want to create goals using objectives and multiple key results, so that I can clearly define and track what I want to achieve.
- As a user, I want to view my goals, so that I can monitor my progress and stay focused on my objectives.
